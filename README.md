## 📌 Project Overview
End-to-end data analytics project analyzing
**15,000 real Flipkart delivery orders** using
Advanced Excel, SQL & Power BI.

## 🛠️ Tools Used
| Tool | Purpose |
|------|---------|
| Advanced Excel | Data cleaning & analysis |
| SQL (MySQL) | Business queries & insights |
| Power BI | 6-page interactive dashboard |

## 📊 Dataset
- **Source:** Kaggle
- **Records:** 15,000 orders
- **Columns:** 31 columns
- **Period:** Jan 2023 – Dec 2023

## 🎯 Problem Statement
Flipkart lacks a centralized data-driven view
to identify delivery delays, return patterns
and customer satisfaction factors.

## 📈 Key Findings
| Metric | Value |
|--------|-------|
| Overall Delay Rate | 41.75% |
| Central Zone Delay | 51% (worst!) |
| Revenue Lost to Returns | ₹9.34M |
| Same-Day Delivery Avg | 1.4 days (best!) |
| Electronics Revenue | ₹43M (top!) |
| Chandigarh Warehouse Delay | 43.09% |

## 💡 Recommendations
1. Fix Standard shipping — 7.1 avg days too slow
2. Focus on Central zone — 51% delay rate
3. Fix Chandigarh warehouse — 43.09% delay
4. Reduce Automotive returns — 167 returns
5. Promote Same-Day delivery — only 1.4 avg days
6. Improve Tier 3 city logistics — 643 returns
